# Stillmotion

**https://bighipadventure.github.io/Stillmotion/**

Stable Diffusion で作ったメタデータ入りの画像から、ローカルLLMで動画用プロンプトを作り、ComfyUI で動画を生成する Web アプリです。

- 画面は GitHub Pages 上にありますが、**処理はすべて使う人のPCの中**で行われます（ComfyUI とローカルLLMに、ブラウザから直接つなぎます）。
- 画像・プロンプト・設定が外部のサーバーに送られることはありません。設定はブラウザ内（localStorage）に保存されます。
- 動画モデルは、ComfyUI で動くワークフローなら何でも使えます（MiniMax H3、Wan など）。
- 文章AIは、OpenAI互換サーバーなら何でも使えます（Bionic、LM Studio、Ollama、llama.cpp など）。

---

## 最初の1回だけの準備

使う前に、このページからの接続を自分のPCの ComfyUI とLLMに許可する必要があります。ページを初めて開くと「はじめに」画面が出て、必要な文字列がそのまま表示されます。

### 1. ComfyUI に接続を許可する（Stability Matrix）

1. Stability Matrix の「パッケージ」で、ComfyUI のカードの歯車アイコンを開く
2. 一番下の「Extra Launch Arguments」に、次の1行を**そのまま**貼り付けて保存する（前後に空白を入れない）
   ```
   --enable-cors-header https://bighipadventure.github.io
   ```
   URL だけでは動きません。先頭の `--enable-cors-header` も必要です。
3. ComfyUI を一度**停止**してから「Launch」で起動し直す（保存だけでは反映されません）

<details>
<summary>Stability Matrix 以外で起動している場合</summary>

- **ポータブル版**: `run_nvidia_gpu.bat` をメモ帳で開き、次のように行の末尾に追記して保存
  ```
  .\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --enable-cors-header https://bighipadventure.github.io
  ```
- **デスクトップ版**: 設定のサーバー設定にある CORS ヘッダーの項目に `https://bighipadventure.github.io` を入力（表記はバージョンにより異なります）
</details>

> この設定は「このサイトがあなたの ComfyUI を操作してよい」という許可です。

### 2. ローカルLLMのサーバーを起動し、CORS を有効にする

- **Bionic**: 設定 →「ローカルモデルAPI」で「ローカルAPIサーバー」と「CORS」をオン
- **LM Studio**: 「Developer」でサーバーを起動し、サーバー設定の「Enable CORS」をオン
- **Ollama**: 環境変数 `OLLAMA_ORIGINS` に `https://bighipadventure.github.io` を設定して起動し直す

### 3. ブラウザは Chrome または Edge

初回の接続時に「ローカルネットワーク上のデバイスへのアクセス」の確認が出たら「許可」を押します。Safari では動かない場合があります。

### 4. ページで設定する

1. 「設定」→「文章AI」→「🔍 自動で探す」→ モデルをプルダウンから選ぶ →「画像対応をテスト」→「保存して使う」
2. 「設定」→「動画（ComfyUI）」→ URL を確認 →「保存して使う」
   - MiniMax H3 の公式テンプレート（画像→動画）が「MiniMax H3（既定）」として最初から入っています。モデルファイル名は公式テンプレートのまま（`minimax_h3_fl2va_pruned_int8_convrot.safetensors`、`minimax_h3_video_vae_int8_convrot.safetensors` など）で、カスタムノードは不要です。公式テンプレートどおり高速化用の Lightning LoRA は OFF（20ステップ）です
   - もう1つ「MiniMax H3 + LoRA（要 rgthree）」も最初から入っています（作者が作った LoRA 入りのワークフロー。rgthree の Power Lora Loader と、使う LoRA ファイルが必要です）。メイン画面の「生成」→「動画」で切り替えられます
   - 別のワークフローを使うときは、ComfyUI で「ワークフロー」→「エクスポート (API)」で JSON を保存し、ここで読み込みます
4. 「設定」→「はじめに」→「いまの設定で接続を確認」で、両方 🟢 になれば完了

## 毎日の使い方

1. 画像をドロップ
2. 「動画のサイズ」で縦横比（ComfyUI の解像度セレクターと同じ8種類）と大きさ（メガピクセル）を選ぶ。画像はその型に合わせて切り抜かれます（余白を足すこともできます）。切り抜く位置は画像をドラッグ、切り抜く大きさ（縦横比は固定のまま）は「切り抜き」のスライダーか画像の上でマウスホイールで調整できます
3. 「プロンプトの指定」で次を選ぶ
   - モード: I2VA（画像が最初のフレーム）／FL2VA（最初と最後の2枚をつなぐ）／L2VA（画像が最後のフレーム）
   - BGM: あり／なし
   - セリフ・歌（話す・歌う・鼻歌・ささやき）: あり／なし
   - 息・声の音（呼吸・息づかい・ため息・あえぎ声・笑い声・叫び声）: あり／なし
   - 動き（人物の動きの大きさ）: 控えめ／ふつう／大げさ
   - カメラ: おまかせ／固定／ズーム（ゆっくり寄る）／場面転換（FL2VA・L2VA では使えません）
   - 狙いたい構図・シチュエーション（自由入力・任意）
   FL2VA のときは、下に出る欄へ最後のフレームの画像を入れます（入れないときは最初の画像を最後にも使い、元の姿に戻る動画になります）。モード・BGM・声は MiniMax H3 のワークフローのときだけ使われます
4. 「本数」を選んで「実行」（右上のゲージは、画像の読み込みからすべての動画の完成までを1本で表した全体の進み具合です）→ プロンプトを作ったあと、同じ画像とプロンプトで指定した本数の動画を ComfyUI に依頼します（ComfyUI が順番に1本ずつ作ります。シードは毎回変わります。シードを固定したときは 100, 101, 102… と1ずつずらします）
   - 日本語訳が不要なときは、左の「生成」→「日本語訳: 作らない」にすると、訳を作らず英語の欄だけを表示します（設定の「バックアップ・初期化」→「日本語訳」と同じ値です）
5. 動画は「動画」欄にパネルで古い順（左）から並びます。生成中のパネルは暗くなり、回転するマークが出ます。完成すると一番新しい動画が自動でプレビューに表示され、パネルを押すと切り替わります（自動再生はしません。再生するとループします）、「この動画を保存」「この動画のプロンプトを保存」でダウンロードできます（ページを閉じると一覧は消えます。ComfyUI の output フォルダには残ります）
6. 気に入らなければ、プロンプトを手で直すか、指示を書いて「AIで修正」→「このプロンプトで動画を作り直す」

画面の選択内容（縦横比・大きさ・合わせ方・長さ・シード・ネガティブプロンプト・最後に開いた設定タブ）はブラウザに保存され、次に開いたときもそのまま使えます。

### ワークフローの細かい設定

左の「生成」→「詳しい設定」を押すと画面中央に設定画面が開き、シード・ネガティブプロンプトと、選んでいるワークフローの中で変えられる値（フォーマット・コーデック・解像度の刻み・FPS・サンプラー・スケジューラー・ステップ数・デノイズ・モデルや VAE のファイル・各 LoRA のオン／オフ・ファイル・強さ、公式テンプレートの Lightning LoRA のスイッチなど）がノードごとのカードで並びます（「閉じる」・Esc・外側のクリックで閉じます。変えている内容はボタンに「シード固定・3件変更」のように表示されます）。

- 選択肢は ComfyUI から読み込むので、ComfyUI と同じ一覧から選べます（ComfyUI につながっていないときは文字で入力できます）
- 変えた項目には ● が付き、次の実行から使われます。ワークフローごとに保存され、「ワークフローの値に戻す」で元に戻せます
- 出力につながっていないノードや、アプリが書き込む値（プロンプト・画像・シード・長さ・縦横比・大きさ）は表示しません

## 動画ができるまで（しくみ）

アプリの「動画ができるまで」ボタンでも同じ説明を見られます。

| # | どこで | 起きていること |
|---|---|---|
| 1 | ブラウザ | PNGに埋め込まれたメタデータ（SDのプロンプト、シード、モデル名など）を読み取る |
| 2 | ブラウザ | 一覧から選んだ縦横比の型に合わせて画像を切り抜く（または余白を足す）。これが動画の最初のフレームになる |
| 3 | 文章AI | プロンプト形式＋スキル＋プロンプトの指定（モード・BGM・声・動き）＋メタデータ＋整えた画像を渡し、動画用の英語プロンプトを書いてもらう |
| 4 | 文章AI | 日本語訳を作る（設定でONのとき） |
| 5 | ComfyUI | 整えた画像を ComfyUI の input フォルダに送る |
| 6 | ブラウザ | ワークフローJSONのコピーに、プロンプト・画像名・シード・長さ・縦横比・メガピクセルを書き込む |
| 7 | ComfyUI | 順番待ちのあと動画（と音声）を生成する。いちばん時間がかかる |
| 8 | ComfyUI | 完成した動画を受け取り、「動画」欄にパネルとして並べる |
| 9 | ComfyUI | GPUメモリを解放する（設定でONのとき） |

「AIで修正」は3〜4だけ、「このプロンプトで動画を作り直す」は5〜9だけをやり直します。

文章AIのモデルは、メイン画面の「使うAI」で切り替えられます（サーバーにあるモデルが一覧で出ます）。

作った動画を人と共有したいときは、設定画面の下のリンクから [Prompt Reel Images](https://bighipadventure.github.io/prompt-reel-images/) を開けます。

## 動画に埋め込まれる情報（メタデータ）

完成した MP4 には、アプリが次の情報を JSON で書き込みます（「この動画を保存」で保存したファイルに入っています）。

- 英語・日本語のプロンプト、自由入力の指示、プロンプトの指定（モード・BGM・声・動き・カメラ）
- 長さ・縦横比・大きさ・シード
- 実際に使われたモデル（拡散モデル・CLIP・VAE）と LoRA（OFF のものは含みません）
- 使ったワークフロー名・文章AIのモデル・スキル
- 元画像のファイル名と SD のメタデータ

書き込み先は MP4 標準のコメント欄（`moov/udta/meta/ilst/©cmt`）で、ffprobe などでは `comment` として表示されます。中身は `"format": "stillmotion-metadata"` を含む JSON です。他のアプリで読み込むときは、同梱の `stillmotion-metadata-reader.js` の `readStillmotionMetadata(file)` を使うと、ドロップされた動画からこの JSON をそのまま取り出せます（Stillmotion の情報がない動画なら `null`）。

```js
dropZone.addEventListener("drop", async (e) => {
  e.preventDefault();
  const meta = await readStillmotionMetadata(e.dataTransfer.files[0]);
  if (meta) console.log(meta.prompt.en, meta.loras);
});
```

SNS などに投稿すると再エンコードされて情報が消えることがあります。

## スキル

プロンプトを作るときに文章AIへ追加で渡す指示です。メイン画面のボタンでON/OFFします。

- Agent Skills 形式（`SKILL.md`）の読み込み・書き出しに対応しています。Bionic などで使っている SKILL.md もそのまま読み込めます
- スキルはこのアプリが文章AIへの指示に追加する仕組みです。Bionic 本体のスキル機能を呼び出すものではありません
- 既定のスキルは MiniMax H3 公式の [h3-prompt-writing](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing)、既定のプロンプト形式は同スキルのガイド（references/base-en.txt）を元にしています。ふだんはこの既定のものが自動で使われます
- 出力は公式の構成どおり「1行目にモード別の参照画像の対応文 → `integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music`」になります。1行目の対応文は、文章AIが書き忘れてもアプリが自動で付け直します
- 自分用のスキルを使いたいときだけ「設定」→「スキル」で読み込みます。追加したスキルはメイン画面にボタンで出て、ONにすると既定のスキルの代わりに使われます
- 既定のスキル・形式を編集したあとでも、「既定の内容に戻す」で元に戻せます

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| 「接続が許可されていません（CORS）」 | 上の手順1・2の許可設定を確認し、ComfyUI / LLM を停止→起動し直す。ページは必ず `https://bighipadventure.github.io/Stillmotion/` から開く |
| 「接続できません」 | 起動しているか、URL（ポート番号）が正しいか確認。ブラウザの「ローカルネットワークへのアクセス」を許可したか確認 |
| 「ComfyUI でデータが足りていない可能性があります」 | ほとんどの場合、ワークフローに必要なノードやモデルが ComfyUI に入っていません。案内に出る不足データ（モデルは入れる場所のフォルダも表示）を確認し、「ワークフローを書き出す」→ ComfyUI の画面にドロップして展開 →「Manager」→「Install Missing Custom Nodes」でノードを、ダウンロード案内か表示されたフォルダでモデルを入れる → ComfyUI で一度動かしてから「このプロンプトで動画を作り直す」 |
| 動画生成がとても遅い | 文章AIと動画が同じGPUを取り合っています。動画生成前に Bionic / LM Studio でモデルを取り外すと速くなります |
| 設定を別のPCに移したい | 「設定」→「バックアップ・初期化」で書き出し・読み込み |
| 設定で「＋ 新しく追加」を押したけれどやめたい | 「編集をやめて戻る」を押すと、直前に見ていた設定に戻ります（入力途中の内容は保存されません） |
| 最初の状態に戻したい | 「設定」→「バックアップ・初期化」→「キャッシュをすべて削除する」。このブラウザに保存された Stillmotion のデータ（設定・登録したワークフロー・スキル・画面の状態・動画の一覧）をすべて消してページを開き直します。生成中の動画は中止されます。ComfyUI の output フォルダの動画は消えません |
