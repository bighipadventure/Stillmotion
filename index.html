はじめての準備

      
このページは、あなたのPCで動いている ComfyUI と ローカルLLM に、ブラウザから直接つなぎます。画像やプロンプトが外部のサーバーに送られることはありません。設定はこのブラウザの中だけに保存されます。

      
    
        
  1. ComfyUI に「このページからの接続」を許可する
    
          Stability Matrix で ComfyUI のカードの歯車アイコンを開き、一番下の「Extra Launch Arguments」に次の1行をそのまま貼り付けて保存します（前後に空白を入れない）。
    
           
          
    保存したら、ComfyUI を一度「停止」してから「Launch」で起動し直してください。保存だけでは反映されません。
    Stability Matrix 以外の場合:
    ポータブル版: 起動用の run_nvidia_gpu.bat をメモ帳で開き、main.py の後ろ（同じ行）に追記して保存。
    デスクトップ版: 設定のサーバー設定に CORS ヘッダーの項目があります（表記はバージョンにより異なります）。値に  を入れます。
    
        
    2. 
        
  2. ローカルLLMのサーバーを起動し、CORS を有効にする
    
          
    Bionic: 設定 →「ローカルモデルAPI」で「ローカルAPIサーバー」と「CORS」をオン。
    
          LM Studio: 「Developer」→ サーバーを起動 → サーバー設定の「Enable CORS」をオン。
    
          Ollama: 環境変数 OLLAMA_ORIGINS に  を設定して起動し直します。
    
        
    3. 
        
  3. ブラウザは Chrome または Edge を使う
    
          
    初回の接続時に「ローカルネットワーク上のデバイスへのアクセス」の確認が出たら「許可」を押してください。Safari では動かない場合があります。
    
        
    4. 
        
  4. 「文章AI（LLM）」タブで「自動で探す」→ モデルを選んで保存
    5. 
        
  5. 「動画（ComfyUI）」タブで ComfyUI のURLを確認して保存（MiniMax H3 のワークフローは最初から入っています。別のワークフローを使うときだけ登録します）
    6. 
      

      
接続の診断

      
      

    


    

      
動画ができるまで

      
「実行」を押してから動画が表示されるまでに、裏側で起きていることを順番に並べました。色のついたラベルは「どこで処理されているか」です。どれもあなたのPCの中で行われ、外部のサーバーには送られません。

      
    
        
  1. 
          
    ブラウザ画像を読み込む
    
          
    ドロップしたPNGの中に埋め込まれた「メタデータ」を読み取ります。Stable Diffusion で画像を作ったときのプロンプト、ネガティブプロンプト、シード、モデル名などです。この時点では画像はまだどこにも送られていません。
    
        
    2. 
        
  2. 
          
    ブラウザ画像を動画の形に整える
    
          
    「動画のサイズ」の一覧から選んだ縦横比（ComfyUI の解像度セレクターと同じ型）に合わせて、画像を切り抜くか、余白を足します。この画像が動画の最初のフレームになります。動画と画像の縦横比がずれていると、動画モデルが画像を引き伸ばしたり、端が欠けたりする原因になります。
    
        
    3. 
        
  3. 
          
    文章AI動画用のプロンプトを書いてもらう
    
          
    「プロンプト形式」（書き方のルール）、「スキル」（追加の指示）、メタデータ、整えた画像（画像対応モデルのとき）をまとめて文章AIに渡し、英語のプロンプトを書いてもらいます。SDのプロンプトは単語の羅列ですが、動画モデルには「何が、どう動き、どんな音がするか」を文章で伝えたほうがうまく動きます。
    
        
    4. 
        
  4. 
          
    文章AI日本語訳を作る（設定でONのとき）
    
          
    確認しやすいように、できた英語プロンプトを日本語に訳します。動画に使われるのは英語のほうです。
    
        
    5. 
        
  5. 
          
    ComfyUI整えた画像を ComfyUI に送る
    
          
    手順2で作った画像を ComfyUI の input フォルダに保存します。
    
        
    6. 
        
  6. 
          
    ブラウザワークフローに値を書き込む
    
          
    登録したワークフロー（JSON）のコピーに、プロンプト・画像のファイル名・シード・動画の長さ・縦横比とメガピクセル（解像度セレクターがない場合は幅と高さ）を書き込みます。登録した元のJSONは書き換わりません。
    
        
    7. 
        
  7. 
          
    ComfyUI順番待ちのあと、動画を生成する
    
          
    ComfyUI がモデルを読み込み、ノイズから少しずつ映像（MiniMax H3 なら音声も）を作っていきます。いちばん時間がかかる手順で、進み具合は画面上部のバーに表示されます。
    
        
    8. 
        
  8. 
          
    ComfyUIできた動画を受け取って表示する
    
          
    完成した動画ファイルを ComfyUI の output フォルダから受け取り、画面で再生します。「動画を保存」でダウンロードできます。
    
        
    9. 
        
  9. 
          
    ComfyUIGPUメモリを片付ける（設定でONのとき）
    
          
    文章AIと動画モデルが同じGPUを取り合わないように、ComfyUI が使っていたGPUメモリを解放します。
    
        
    10. 
      

      
やり直すときに動く手順

      
「AIで修正」は手順3〜4だけ、「このプロンプトで動画を作り直す」は手順5〜9だけをやり直します。画像の読み込みや、文章AIへの依頼をくり返さないので早く終わります。

    


    

      
文章AI（LLM）

      
OpenAI互換のサーバー（LM Studio / Bionic、Ollama、llama.cpp など）に対応しています。複数登録して、メイン画面で切り替えられます。

      

      
サーバーを起動してから押してください

      
      
      

        
        
      

      

        
        
      

      

        上級者向け
        
        
        
      

      

      

    


    

      
動画（ComfyUI）

      
ComfyUI でふだん動いている画像→動画のワークフロー（MiniMax H3、Wan など）をそのまま使います。MiniMax H3 のワークフローは最初から「MiniMax H3（既定）」として入っています。

      

      
      

        
        
      

      
ワークフローの登録

      
    
        
  1. ComfyUI でワークフローを開き、一度ちゃんと動画が作れることを確認
    2. 
        
  2. メニューの「ワークフロー」→「エクスポート (API)」（Export (API)）で JSON を保存
    3. 
        
  3. その JSON を下で選ぶ → 書き込み先が自動で選ばれます
    4. 
      

      

      
      

      

        書き込み先の確認・変更（自動検出が違うときだけ）
        

      

      
動画の作り方

      
      

        
      

      
動画の縦横比と大きさは、メイン画面の「動画のサイズ」で選びます。

      
      

      

    


    

      
スキル

      
プロンプトを作るときに文章AIへ追加で渡す指示です。Agent Skills 形式（SKILL.md）の読み込み・書き出しができ、Bionic などで使っている SKILL.md もそのまま読み込めます。使うスキルはメイン画面で選びます。

      

      

        
        
      

      
      
      
      

      

    


    

      
プロンプト形式

      
動画モデルごとの基本の書き方です（文章AIへの指示文）。{seconds} は動画の秒数に置き換わります。動画の設定ごとにどれを使うか選べます。

      

      
      
      

      

    


    

      
バックアップ・その他

      
      
設定の書き出し・読み込み

      
別のブラウザやPCに設定を移すときに使います。書き出したファイルには APIキーも含まれるため、他人に渡すときは注意してください。
